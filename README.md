<h1 align="center">WokCloud Utils</h1>

<p align="center">Utilitários para apoiar os projetos e as integrações da WokCloud.</p>

## Estado do projeto

O repositório está em preparação. Contém documentação e a licença; ainda não inclui uma implementação nem um `package.json`. A instalação através de npm e os exemplos de utilização serão documentados quando existir uma versão publicada e verificada.

Os apontamentos iniciais abrangem informação de recursos, mensagens de terminal e registo de eventos. A API pública e a organização dos módulos serão definidas com a implementação.

A [documentação inicial](https://github.com/wokcloudofc/wokcloud-utils/blob/e240c412a6a315acef3ec30961e22324891a0ef8/README.md) continua disponível no histórico, como referência do trabalho anterior.

## Participar

Lê o [guia de contribuição](CONTRIBUTING.md) antes de propor uma alteração. Usa os modelos de issues para comunicar um erro ou explicar uma melhoria. Os pedidos de alteração são revistos pela equipa através de pull requests.

A [verificação automática](.github/workflows/verificacao.yml) valida os ficheiros essenciais e as ligações internas da documentação. Os testes da biblioteca serão acrescentados juntamente com a implementação.
