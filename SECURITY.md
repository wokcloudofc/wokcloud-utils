# Segurança

Comunica possíveis vulnerabilidades pelo suporte privado do painel [WokCloud](https://www.wokcloud.pt/dashboard). Indica que se trata de uma questão de segurança e fornece o repositório, a versão ou commit afetado, o impacto provável e os passos mínimos de reprodução.

Não publiques tokens, palavras-passe, dados de pagamento, ficheiros de clientes ou detalhes de uma vulnerabilidade ainda sem correção numa issue pública. Revoga uma credencial exposta no respetivo fornecedor.

Usa apenas recursos próprios ou ambientes para os quais tens autorização. Este documento não concede autorização para testar contas ou serviços de terceiros e não estabelece um programa de recompensas ou um prazo garantido de resposta.
